> **Практичне завдання з JavaScript:** Умовні конструкції (`if/else`, `switch`), логічні оператори (`&&`, `||`, `!`) та робота з числами.

## 🪐 Сюжет місії

Рік 2030. Червона планета, кратер Гейла.
Автономний марсохід **Ares-7** досліджує поверхню Марса для майбутньої колонії. Під час останньої сонячної бурі модуль штучного інтелекту частково втратив налаштування безпеки.

Твоя роль — головний системний програміст місії в ЦУП на Землі. Тобі необхідно відновити скрипти автопілота:
1. Аналізувати загрозу радіації для бортової електроніки.
2. Приймати рішення щодо безпеки виходу марсохода на новий маршрут.
3. Розраховувати витрати палива з урахуванням марсіанського ландшафту.

## 📋 Завдання

Відкрийте файл [`src/rover.js`](src/rover.js) та реалізуйте три функції:

### 1. `checkRadiationSafety(radiationLevel, isShieldActive)`
- Якщо рівень радіації менше 50 (`< 50`) — безпечно, повертає `'SAFE'`.
- Якщо рівень радіації 50 або більше (`>= 50`):
  - Якщо магнітний щит активний (`isShieldActive === true`) — повертає `'WARNING'`.
  - Якщо щит неактивний — повертає критичну небезпеку `'DANGER'`.

### 2. `canStartExpedition(batteryLevel, weather, oxygenTanks)`
Всюдихід може вирушити в експедицію (`true`), тільки якщо виконуються **всі три умови**:
1. Заряд батареї не менше 60% (`batteryLevel >= 60`).
2. Погода сприятлива: `'clear'` або `'cloudy'`. Якщо `'storm'` — виїзд суворо заборонено!
3. На борту є щонайменше 2 запасні балони з киснем (`oxygenTanks >= 2`).
В інших випадках повертає `false`.

### 3. `calculateTripFuel(distanceKm, fuelPerKm, terrainType)`
- Якщо `distanceKm <= 0` або `fuelPerKm <= 0` — повертає `0`.
- Базова формула: `distanceKm * fuelPerKm * коефіцієнт`.
- Коефіцієнт залежить від `terrainType`:
  - `'flat'` (рівнина) -> `1.0`
  - `'rocky'` (кам'янистий рельєф) -> `1.3`
  - `'sand_dunes'` (піщані дюни) -> `1.8`
  - будь-який інший -> `1.0`
- Результат округліть до одного знака після коми: `Math.round(fuel * 10) / 10`.

## 🛠️ Як працювати з проєктом

### 1. Встановлення залежностей
```bash
npm install
```

### 2. Запуск тестів
```bash
npm test
```
*Для перевірки наживо під час написання коду:*
```bash
npm run test:watch
```

## 🚀 Як здати роботу через GitHub

1. Зробіть **Fork** цього репозиторію у свій GitHub-акаунт.
2. Склонуйте ваш форк на комп'ютер:
   ```bash
   git clone <посилання-на-ваш-fork>
   ```
3. Виконайте завдання у файлі `src/rover.js`.
4. Перевірте тести (`npm test`).
5. Збережіть і відправте код:
   ```bash
   git add .
   git commit -m "feat: implement rover navigation system"
   git push origin main
   ```
6. Перевірте статус у вкладці **Actions** репозиторію — там має загорітися зелена галочка ✅.
